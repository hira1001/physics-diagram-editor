# ISSUE-004: 推論スナップ（Smart Snapping / Alignment Guides）の実装

## 概要 (Overview)
画面右下やツールバーに「推論スナップ (SNAP)」の切り替えボタンが存在しますが、現状のコードでは操作中の角度・寸法の数値四捨五入 (`Math.round`) にしか利用されておらず、図形要素の移動時におけるグリッド吸着や他の図形との整列（X/Y中心揃え、エッジ揃え、接続点吸着などの推論ガイド）が全く動作していません。

本チケットでは、図形移動・配置時における「真の推論スナップ（Smart Alignment Snapping & Guides）」機能を実装します。

## 不具合・原因分析 (Root Cause Analysis)
- `EditorCanvas.tsx` 内の `dragMode === "element"`（要素移動処理）において、`nextX`, `nextY` がマウスの絶対移動量そのまま（連続値）で更新されており、他の要素の座標やグリッドへの投影・吸着計算がスキップされている。
- 推論スナップ作動時のガイドライン（赤・青の破線など）の描画レイヤー処理が存在しない。

## 要求仕様 (Requirements)
1. **グリッド & オブジェクト軸推論スナップ (Smart Snapping)**:
   - 要素を移動中、他要素の X座標 / Y座標（中心または端点）と一致する近傍（例: 8px以内）に近づいた場合、X軸・Y軸それぞれ独立して吸着する。
   - グリッド表示時 (`scene.grid === true`) は、一定間隔（例: 10px / 20px）のグリッド交点へ吸着する。

2. **推論ガイドラインの描画 (Inference Alignment Guides)**:
   - スナップが有効になった軸上に、一時的なアライメントガイド線（点線・ハイライト表示）を表示する。

3. **一時解除操作 (Modifier Key)**:
   - `Option` (Mac) / `Alt` キーを押しながらドラッグした場合は、一時的に推論スナップを無効化して自由移動できるようにする。

## 対象コンポーネント (Affected Files)
- `app/components/EditorCanvas.tsx`: 要素移動時のスナップ計算処理、スナップガイドライン描画
- `app/lib/diagram-model.ts`: 近接エレメント・軸計算ユーティリティ
