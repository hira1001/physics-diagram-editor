# ISSUE-002: テンプレート追加時の不具合（配置の重複・対象シートの誤り）

## 概要 (Overview)
テンプレート選択機能において、以下の2つの不具合が報告されています。
1. **配置の重複（ごちゃごちゃになる）**: 既存の図が存在するシートでテンプレートを選択した際、テンプレートの図形が既存の図の上にそのまま配置（または既存の図を上書き）され、描画領域が混雑・錯乱する。
2. **対象シートの誤り**: アクティブなシート（2番目以降のシート）でテンプレートを選択しても、一番最初のシート（1番目のシート）にテンプレートが配置されてしまう。

## 不具合の原因分析 (Root Cause Analysis)

### 1. 配置の重複の原因
- `buildTemplateScene(template)` が生成するテンプレート要素の座標が固定値（例: $x=450, y=420$ 付近）となっている。
- テンプレート適用時に新規シートを作成せず、また既存の要素群との衝突を回避・オフセット・クリアの選択を行わずにそのまま適用/置換しているため、中心付近の既存要素と重なってしまう。

### 2. 対象シートの誤りの原因 (`PhysicsEditor.tsx`)
- `activePage` の算出ロジックは `workspace.activePageId` が不整合の際に `workspace.pages[0]`（1番目のシート）へフォールバックする仕組みになっている。
- 一方で `applyTemplate` や関連処理で `current.activePageId` を参照する際、シート切り替え時の `activePageId` 同期が不十分な場合、常に `workspace.pages[0]` に対しても適用されてしまう構造となっていた。

## 改善策の提案 (Proposed Fixes)

1. **アクティブシートの厳格な特定と反映**:
   - `applyTemplate` 実行時に確実に現在アクティブな `activePage.id` を対象として更新するように修正。

2. **テンプレート適用方法の改善（UX向上）**:
   - **新規シートとして追加**: テンプレート選択時は既存のシートを破壊・混雑させず、自動的に新しいシート（タブ）を作成してテンプレートを配置する（推奨）。
   - **既存シートへの追加時の自動位置オフセット / 上書き確認**: 仮に同シートに追加する場合は、既存図形のバウンディングボックスを計算し、重ならない位置にオフセット配置するか、既存図形の上書き確認ダイアログを表示する。

## 対象コンポーネント (Affected Files)
- `app/components/PhysicsEditor.tsx`: `applyTemplate` 処理およびシートID解決
- `app/components/LibraryPanel.tsx`: テンプレート選択イベントハンドラ
