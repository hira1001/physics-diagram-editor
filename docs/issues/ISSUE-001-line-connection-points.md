# ISSUE-001: オブジェクトの線上・エッジへの接点接続機能の追加

## 概要 (Overview)
現状、物理図形エディタにおける接続要素（糸・バネ・ロープ・棒など）の始点・終点は、接続先オブジェクトの「中心座標 (x, y)」を基準に接続されています。
本チケットでは、オブジェクトの中心だけでなく、線分要素（斜面・トラック・ロープ等）の線上や、図形要素（ブロック・板等）の外周エッジ上の任意の位置に接続点（アンカー）をスナップ・固定できるようにデータモデルおよびUI操作を拡張します。

## 要求仕様 (Requirements)
1. **データモデルの拡張**:
   - `startRatio` / `endRatio`（線上媒介変数 $t \in [0.0, 1.0]$）または `startOffset` / `endOffset`（ローカルオフセット）を接続要素のデータ構造に追加。
   - 既存の「中心接続」データとの後方互換性を維持（未指定時はデフォルトで従来挙動または $t=0.5$ / エッジ中心）。

2. **位置解決（Renderer / Model）**:
   - `resolveDiagramElement` で対象オブジェクトの回転角・長さを考慮し、比率 $t$ から正確な世界座標 $(x, y)$ を算出。
   - 対象オブジェクトが移動・回転・変形された場合も、接続点が線上追従すること。

3. **キャンバス操作 & スナップ (Editor Canvas UI)**:
   - 接続線の始点/終点ハンドルをドラッグ中に、対象要素の線上またはエッジに近接した際、線上の最近接点にスナップ表示。
   - スナップ位置の比率 $t$ をリアルタイムに反映。

4. **インスペクタパネル (Inspector Panel UI)**:
   - 接続線のプロパティ表示に「接続位置（線上比率 % または オフセット）」調整UIを追加。

## 対象コンポーネント (Affected Files)
- `app/lib/editor-types.ts`: データ構造定義の更新
- `app/lib/diagram-model.ts`: 座標解決・位置更新ロジックの修正
- `app/components/EditorCanvas.tsx`: キャンバス上でのスナップ・ドラッグ描画処理
- `app/components/InspectorPanel.tsx`: 接続位置調整プロパティ表示
