# ISSUE-006: 図形要素の拡大・縮小・自由変形（伸ばし/縦横変形）機能の実装

## 概要 (Overview)
物理図形エディタにおいて、設置した各種オブジェクト（物体、床、壁、トラック、図形等）に対して柔軟な拡大・縮小・引き伸ばし（縦横の非等比変形）が行えないという不具合・改善要望です。

現在、単一のハンドルによる対称なリサイズしか用意されておらず、CADやデザインツールのような8方向（四隅・四辺）の変形ハンドルや縦横独立ストレッチが機能していません。

## 不具合・現状の制限 (Root Cause & Current Limitations)
1. **変形ハンドルの不足**:
   - 選択枠に四角ハンドル（NW, NE, SE, SW, N, E, S, W の8点）が存在せず、四隅または辺をドラッグしての縦伸ばし・横伸ばしができない。
2. **縦横非等比変形の未対応**:
   - `width` と `height` の個別引き伸ばし処理が不完全（あるいは単一ハンドルで一括変更される）。
3. **アスペクト比維持 / 自由変形モードの切り替え**:
   - `Shift` キー押しでの縦横比固定拡大縮小、標準ドラッグでの自由縦横ストレッチなどの操作分けが未実装。
4. **インスペクタでの数値指定プロパティ不足**:
   - 各図形要素の `幅 (width)` / `高さ (height)` / `スケール (scale)` を直接数値入力して変更するUIが不足。

## 要求仕様 (Requirements)
1. **8ポイントバウンディングボックス変形ハンドルの表示 (8-point Transform Box)**:
   - 選択された要素に 8つの変形ハンドル（四隅 ＋ 上下左右の4辺の中点）を表示する。
2. **柔軟な引き伸ばし・リサイズ操作**:
   - **四辺ハンドル (N/S/E/W)**: 横方向のみ、または縦方向のみの引き伸ばし（ストレッチ）。
   - **四隅ハンドル (NW/NE/SE/SW)**: 自由リサイズ（デフォルト）および `Shift` キー押しでのアスペクト比固定リサイズ。
3. **回転考慮の変形ロジック (Rotated Bounding Box Transform)**:
   - 要素が回転している場合（`rotation != 0`）でも、ローカル軸に沿って正しく縦横ストレッチができる幾何計算を組み込む。
4. **インスペクタでのサイズ数値変更**:
   - インスペクタパネルに「幅 (W)」「高さ (H)」の数値入力フィールドを追加し、キーボード入力でも精密なサイズ変更を可能にする。

## 対象コンポーネント (Affected Files)
- `app/components/EditorCanvas.tsx`: 8点変形ハンドルの描画、回転考慮の変形ドラッグロジック
- `app/components/InspectorPanel.tsx`: `width` / `height` プロパティ入力の追加
