# プロダクト認識合わせ (Product Alignment)

最終更新: 2026-07-25（プロダクトオーナー合意反映）

## 1. 今やること / 今やらないこと

| やる | やらない（当面） |
|------|------------------|
| **力学図エディタ本体**（キャンバス・部品・物理意味・出力） | Cloudflare / ChatGPT Sites ホスティング、SIWC、D1/R2 の本番設計 |
| 大学初級力学 **と** 土木・構造力学の両方 | 「高校だけ」「構造はサブ」という優先度付け |
| 少クリック・テンプレ・シナリオ品質 | 319 件マトリクスを唯一のリリースゲートにすること |

ホスティング用 README の vinext 説明は**インフラの足場**であり、プロダクトの目的ではない。

## 2. North Star（北極星）

> **PPT/CAD より操作が少なく**、**教科書品質**の図を、**物理・構造の意味が正しい状態**で素早く作り、教材・問題・レポートに載せられる形で出す。

成功の体感指標（ISSUE-011 準拠）:

- 代表シナリオで **3〜5 クリック**（または同等の少数操作）で「載せられる1枚」に近づく
- 自動テストは **シナリオ E2E + 単体 + P0 回帰** を主とする（下記 §5）

## 3. 対象領域（主戦場）

**力学（大学初級）** と **土木・構造力学** は **同格の主戦場** とする。

| 領域 | 例 |
|------|-----|
| 力学 | 斜面、自由体図、滑車、Atwood、ばね、円運動、接触・摩擦 |
| 構造力学 | 単純梁、片持ち、ラーメン、支点・分布荷重、SFD/BMD、部材・接合 |

部品カタログ・テンプレは両領域を **同じエディタ・同じ `elements` モデル** で扱う。どちらかを「ライブラリの奥」に隠さない。

### 補足（以前の「ペルソナ1つ」質問について）

「第一ペルソナを高校だけにするか」という話は、**単一ユーザー像に絞るか**の確認だった。  
合意: **高校・大学・土木を分けて優先度を切らない**。初級力学と構造力学の **両方** を最初から満たす。

## 4. データモデル方針：レガシー斜面は不要

**レガシー斜面ウィザード**（`selectedId: "incline" | "block"`、`showGravity`、`angle` / `blockPosition` による専用描画・専用 HUD）は **新規開発・新規 UX の対象外**。

| 採用する | 廃止・移行する |
|----------|----------------|
| `scene.elements` / `variables` / `constraints` | レガシー選択 ID とレガシー専用キャンバスレイヤ |
| カタログ部品 + テンプレ（`template-builder`） | 左パネル「基本ツール」のレガシー `ToolId` 経路 |
| テンプレ適用 → 新規シート | 初期シーンのレガシー斜面デフォルト（将来はテンプレ or 空白カタログ） |

互換: 保存データにレガシーフィールドが残っていても **読み込み時に正規化 or マイグレーション** する。UI からレガシー経路は出さない。

実装の正本: `diagram-model` + `component-catalog` + `catalog-renderer` / `catalog-svg` / 出力層。

## 5. 品質・テスト方針（319 マトリクスについて）

[`QUALITY-TEST-MATRIX.md`](./QUALITY-TEST-MATRIX.md)（319 件）は **要件の辞書・トレーサビリティ用** として残してよいが、**日々の完了判定やリリースゲートの主役にしない**。

日常のゲート:

1. `npm run typecheck`
2. `npm run test:unit`
3. 代表 **シナリオ E2E**（力学 + 構造各1本以上を維持・拡張）
4. 変更に関係する P0 項目のみマトリクスを更新（全体 100% は追わない）

シナリオ例（拡張可）:

- 力学: テンプレ斜面 → 物体選択 → 力を全部 → SVG/PPTX 出力
- 構造: 単純梁テンプレ → 部品編集 → 出力

## 6. ロードマップの優先（機能）

1. **レガシー削除・`elements` 一本化**（UI・描画・エクスポート）
2. **少クリックシナリオ**（力一括、成分分解、ドッキング、テンプレ拡充）
3. **接続・幾何**（ISSUE-001 線上接点、滑車糸、連動拘束）
4. **編集快適性**（複数選択移動、Z オーダー、整列）— PPT 並みの整え作業
5. 出力の実機確認（PowerPoint 等）は必要時のみ
